# HONEE for Tootega AIAD (Windows)

This repository is an import of **[HONEE](https://gitlab.com/phypid/honee)** (High-Order
Navier-stokes Equation Evaluator, part of the [CEED](https://ceed.exascaleproject.org) ecosystem),
maintained for **Tootega AIAD** (Artificial Intelligence-Aided Design), a Windows-only CAD/CAE tool
built on OpenUSD, DirectX 12 and CUDA.

HONEE is hosted on GitLab, so GitHub cannot fork it directly. The full `main` history was
imported, and the GitLab project is kept as the `upstream` remote.

> The original README is kept unchanged in **[README.upstream.md](README.upstream.md)**.
> Everything about HONEE itself (problems, options, examples) is documented there.

## Why this fork exists

AIAD uses HONEE for **compressible flow** (nozzles, ducts, shocks, high-speed aerodynamics). HONEE
is built with Makefiles on top of libCEED and PETSc and runs on Linux clusters, while AIAD runs
**only on Windows** by design (one environment, no WSL). This fork makes `navierstokes.exe` build
and run natively on Windows with NVIDIA GPUs.

## What changes (and why)

| Change | Why |
|--------|-----|
| Windows build (CMake or MSBuild) with **MSVC v145**, and **clang-cl** where C99 VLAs are used | MSVC's C compiler does not support VLAs |
| Built on [libceed-4AIAD](https://github.com/HermesSilva/libceed-4AIAD) and [petsc-4AIAD](https://github.com/HermesSilva/petsc-4AIAD) | the Windows versions of its two dependencies |
| **CUDA** backend (`-ceed /gpu/cuda/*`) | GPU execution on the workstation's NVIDIA card |
| Windows paths and process handling in the executable | AIAD launches `navierstokes.exe` as a separate process |

AIAD writes the mesh (generated by Netgen) and a YAML options file, launches the job, and reads the
results back into the OpenUSD stage. No change to HONEE's numerics or options is intended.

## Status

**No source changes yet.** At this point the only differences from upstream are this README, the
original README renamed to `README.upstream.md`, and the two documentation pages that include it
(`index.md`, `doc/intro.md`). The Windows conversion is planned in the AIAD roadmap (spike S7,
milestone F9).
